# Das Hordenlager

Schauplatz von Kapitel 5: kampflose Einnahme der Verengung, eigenes Lager, Rast, Siegestrunk. Kein Kampf in diesem Kapitel.

## Überblick

Hinter der Ebene schiebt sich von links ein **Felsvorsprung** ins Tal
und drückt den Pass auf eine **Verengung** zusammen – ein paar Dutzend
Schritte breit, zwischen Fels und Felsgrat. Dahinter öffnet sich das
Tal wieder in zwei Richtungen: Links liegt der **Kessel**, eine vom
Fels umschlossene Bucht, eine Sackgasse. Rechts, um eine Felsnase
herum, läuft die Schlucht weiter und **offen** ins Land vor Burg
Veldgard aus. Kein Tor, keine Mauer, keine Schleuse.
