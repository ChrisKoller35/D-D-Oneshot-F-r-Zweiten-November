# Die Greifen der Staffel – Statistiken

Lenja selbst hat keine Werte (nur Charakterbeschreibung, →
`../Beschreibung.md`). Hier stehen die vier Greifen.

## Greif (4 Stück: Sturm, Schiefer, Mohn, Grauwind)

| | |
|---|---|
| Typ | Monstrosität, Groß |
| RK | 12 |
| TP | 59 (Sturm: 70) |
| Bewegung | 9 m, Fliegen 24 m |
| STR 18 (+4) | GES 15 (+2) |
| KON 16 (+3) | INT 2 (−4) |
| WEI 13 (+1) | CHA 8 (−1) |
| Sinne | Dunkelsicht 18 m, Wahrnehmung +5 |
| HG | 2 |

**Mehrfachangriff:** Schnabel (Nahkampf +6, 1W8+4 Stich) und Klauen
(Nahkampf +6, 2W6+4 Hieb).

**Trägt:** Einen Reiter plus einen Passagier (mittelgroß). Mit zwei
Passagieren fliegt der Greif halb so schnell.

**Der große Barbar (fast 3 m / 10 Fuß):** Ein normaler Greif trägt ihn.
Der Charakter bleibt regeltechnisch **mittelgroß**, der Greif ist **groß**
(ein Reittier muss eine Größe über dem Reiter liegen) und hat mit STR 18
eine Tragkraft von 540 Pfund / rund 245 kg – das reicht für Barbar, Rüstung
und Gepäck. Nur wenn er im Kampf **groß** wird (*Vergrößern*, Rune Knight),
bräuchte er ein riesiges Reittier; auf dem Greifen also vorher nicht
wachsen.
